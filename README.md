# Matn Tahlilchisi (30-mavzu)

**Frontend dasturlash asoslari** fanidan mustaqil ta'lim loyihasi.

## Loyiha haqida
Ushbu veb-ilova foydalanuvchi kiritgan matnni real vaqt rejimida tahlil qiladi va quyidagi ko'rsatkichlarni hisoblab beradi:
- Jami belgilar soni (bo'shliqlar bilan)
- Bo'shliqlarsiz belgilar soni
- So'zlar soni (o'zbek tilidagi `o'`, `g'` belgilari hisobga olingan)
- Jumlalar soni
- Matnda eng ko'p uchragan 5 ta so'z ro'yxati

## Ishlatilgan texnologiyalar
- **HTML5**: Semantik teglar (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`) va inline SVG sxema.
- **CSS3**: Flexbox asosidagi ikki ustunli maket, CSS o'zgaruvchilari va `@media` orqali planshet hamda mobil qurilmalarga moslashuvchanlik.
- **JavaScript (ES6+)**: DOM bilan ishlash, `input` hodisasini real vaqtda kuzatish, massiv va obyektlar yordamida chastota tahlili.

## Ishga tushirish tartibi
1. Repozitoriyni kompyuterga yuklab oling (`git clone ...`).
2. Loyiha papkasidagi `index.html` faylini istalgan zamonaviy brauzerda oching.
